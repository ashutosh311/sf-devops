# SF UK&I DevOps Centre of Excellence Resources README #

## What is this repository for? ##

This repository hosts all the reusable scripts and Metadata which can be employed on our projects.

## Development Standards ##

Our [development standards](https://bitbucket.org/slalom-consulting/sf-uki-devops/src/main/devops/standards/) have now been migrated from Confluence/Word format to this DevOps repository, enabling AI to follow the same standards as our team. The standards should be considered the baseline to be used for new projects. Client specific adaptations are allowed (e.g. naming conventions, design patterns) if the client uses a different pattern.
